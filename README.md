# My Personal Web Page

A small project: a personal web page built with HTML and CSS. It is about me, Andreea, and my orange cat Miui.

## What's on the page

- A header with my name and a short introduction
- A profile photo with alternative text
- A list of my hobbies (gaming, reading, playing with my cat)
- A link to my favorite website, [W3Schools](https://www.w3schools.com)
- A table with my cat's profile (name, age, fur color, personality)
- A contact form
- A footer
